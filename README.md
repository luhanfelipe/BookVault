# BookVault

Uma biblioteca pessoal para organizar, acompanhar e documentar sua jornada de leitura.

> O BookVault está em desenvolvimento. A ideia é construir o projeto enquanto exploramos novas tecnologias e conceitos de desenvolvimento web.

## Sobre o projeto

O BookVault nasceu da ideia de ter um espaço pessoal para registrar livros, acompanhar leituras e guardar informações como avaliações, status e observações.

Além de ser uma aplicação útil, o projeto também funciona como espaço de aprendizado e experimentação.

## Tecnologias

### Frontend

* React
* TypeScript
* Vite

### Backend

* C#
* ASP.NET Core *(planejado)*

## Estado atual

O projeto está em estágio inicial de desenvolvimento.

Até agora, a estrutura base do frontend foi criada com React, TypeScript e Vite.

## Próximos passos

O desenvolvimento continuará de forma incremental, acompanhando as issues do projeto. Entre os próximos passos estão a construção da interface e o início do backend em C#.
